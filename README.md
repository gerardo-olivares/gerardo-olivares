## 📂 Featured Projects

### 📉 [Telco Customer Churn — Random Forest Classifier](https://github.com/gerardo-olivares/telco-churn-classification)
End-to-end classification pipeline on 7,043 telecom customers. Includes EDA, Welch t-test + ANOVA hypothesis testing, StandardScaler, PCA, and GridSearchCV-tuned Random Forest.
- ROC-AUC: **0.843** | F1-Score: **0.628**
- Top predictor: `tenure` — churn risk peaks in the first 12 months
- Contract type drives churn rate from 42.7% (month-to-month) to 2.8% (two-year)

### 🏠 [Airbnb Price Analysis — Multiple Linear Regression](https://github.com/gerardo-olivares/airbnb-price-analysis)
Regression model on 64,000+ Airbnb listings across 6 U.S. cities. Full EDA, outlier removal, hypothesis testing, VIF-based feature selection, and OLS modeling.
- R²: **0.536** | MAE: **$58.72 USD**
- Room type is the strongest categorical driver (eta² = 0.37)
- City-level price differences confirmed via ANOVA (F = 572.07, p ≈ 0.00)
